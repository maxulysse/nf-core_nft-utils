# nf-core/nft-utils: agents

This is a plugin repository for nf-test.
Follow the conventions described in docs/CONTRIBUTING.md.

## Rules

- British spelling in documentation and comments.
- No emdashes in prose.
- Commits: one logical change, imperative mood, run `prek` before committing.
- PRs: single feature, entry in CHANGELOG.md.
- Tests: do not edit snapshot files manually. Update with `nf-test test --update-snapshot`.
- Do not commit to `main`. Use pull requests.
